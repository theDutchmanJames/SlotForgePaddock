# SlotForge Paddock v0.17.1

A small patch correcting the parts summary on Overview.

- **Unique parts count:** the Overview tile now counts inventory entries, matching the Parts folders. For example, 10 entries containing 2,023 pieces display **10 unique parts**. Quantities and stock records are unchanged.
- **README highlight:** a dedicated section explains gearing, torque, theoretical speed, power curves and build comparisons.

Download **SlotForge.Paddock.0.17.1.exe** and close the previous version before opening it. It is the Windows portable app; no installer or Node.js is required. The executable is unsigned. `SHA256SUMS.txt` covers the executable and the unchanged Timing integration handoff ZIP.

There is **no database or Timing API change from v0.17.0**. If upgrading from v0.16.3, create a complete backup first: schema-9 saves cannot be opened by that older version.

All features and platform limitations from [v0.17.0](https://github.com/theDutchmanJames/SlotForgePaddock/releases/tag/v0.17.0) still apply. Linux/macOS builders are included in the source; native binaries are not provided here.

Validation: syntax checks and all **253 automated tests passed**. The packaged app was checked with 0, 1 and 10 inventory entries containing large quantities; its Overview displayed the entry count correctly. All 177 packaged source and asset files match the reviewed files.
