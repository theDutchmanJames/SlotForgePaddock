# SlotForge Paddock v1.2.1

Smoother result imports, quieter connected-car updates and safer save retries.

## Improvements

- **Background race-result processing.** Timing uploads are parsed, validated, calculated and saved in a worker so the main app can keep responding. Checking a delivered result reads only that session.
- **Refresh only affected cars.** Renaming a fitted part or changing an installation refreshes the relevant cars. Spare-stock quantities, locations and unused parts no longer trigger a full catalogue refresh. Large stock imports also leave unrelated result caches alone.
- **Durable save receipts.** Personal-database saves retain an identity and result atomically with their changes. Retrying the same save after a lost acknowledgement cannot duplicate stock installations or history. Restore generations and conflicting retries are checked explicitly.
- **Safer background work.** Bounded queues, timeout/crash recovery, lazy photo transport and compressed bulk-operation receipts protect responsiveness and existing editing workflows.

Timing, Telemetry and Dealership Mode retain their existing APIs, credentials, captured configurations and review behavior. **No companion-app update or new connection setting is required.**

## Performance

In a local synthetic 10,000-lap test, the longest main-thread timer gap fell from approximately **564 ms to 19 ms**. Total processing time was similar: the improvement is responsiveness while results are processed. Results vary by computer and collection.

## Updating and downloads

Close Paddock before replacing the app and retain a current backup of your collection. Existing SQLite data continues to work; there is no new storage-format migration.

- **Windows:** `SlotForge.Paddock.1.2.1.exe` — portable app.
- Native **Linux x64/ARM64** packages and **universal macOS** packages are attempted by GitHub Actions after publication. If macOS fails, this release proceeds with the other verified downloads.
- Timing, Telemetry and scalable API handoff ZIPs, plus SHA-256 checksums.

Windows is unsigned. macOS downloads, when available, are ad-hoc signed and not Apple-notarised.

## Validation

- **670 Paddock regression tests**, **122 Timing integration tests** and **23 Telemetry client/interoperability tests** passed.
- **210 Electron desktop checks** passed with zero captured renderer errors.
- Packaged Windows workers passed result processing, receipt replay after restart, corrections, withdrawals and exact backup restoration checks.
- A real worker-exit test verifies that a save committed before its acknowledgement is not repeated when retried.

Testing used artificial collections and local servers. Native build outcomes are shown in GitHub Actions; these checks do not replace installation testing or a new test across two physical computers.
