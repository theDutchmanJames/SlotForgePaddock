# SlotForge Paddock v1.1.1

Clearer reviews, control over individual incoming fields, and faster Dealership proposal saves.

## Improvements

- **Recognisable reviews:** Dealership cards identify the car and the work being proposed, including jobs started from setups and checklist changes.
- **Choose individual technical fields:** compare incoming values with the current car and select which changes to accept. Unselected fields remain unchanged.
- **Override fitted parts:** explicitly return a conflicting fitted component to stock when accepting its replacement specification. Partial assemblies retain their other fitted components; returning the final component dismantles the assembly. A replacement text value does not automatically install another inventory part.
- **Distinct livery classifications:** clearer, themed labels make classifications easier to recognise.
- **Faster history proposals:** send only changed history fields, reuse photo encoding, avoid repeated validation, and save proposal receipts asynchronously. Review lists no longer repeatedly embed full-size photographs.

## Reliability fixes

- Serialize competing writes safely and recheck permissions and database identity after waiting.
- Keep Timing configuration capture working while a proposal is being saved.
- Persist proposals before acknowledging delivery and wait for an outstanding save during normal shutdown.
- Preserve unrelated history fields and photos; remove outdated research evidence when its value changes.
- Strengthen stock-return, assembly, stale-review and failed-write handling.

## Updating and downloads

Close Paddock before opening the new version. Existing collections and remembered Dealership passwords remain in place. Database schema **11** and the Timing and Telemetry API versions are unchanged. Use matching Paddock versions across Dealership computers for the updated review and sparse-history behaviour.

- **Windows:** `SlotForge.Paddock.1.1.1.exe` — portable app; Node.js is not required.
- **Linux:** x64 and ARM64 AppImage/deb packages.
- **macOS:** universal DMG/ZIP for Intel and Apple Silicon.
- Timing and Telemetry integration handoff ZIPs are included.

Native Linux and macOS build jobs attach their downloads after publication. SHA-256 manifests accompany the downloads. Windows is unsigned; macOS is ad-hoc signed and not Apple-notarised. AppImages need executable permission.

## Validation

**418 automated tests passed**, plus syntax checks, isolated Electron interface checks and a shutdown-during-save check. Tests cover selected-field approval, stock conservation, assemblies, concurrent requests, permissions, duplicate deliveries, disk failures and restart persistence.

On a synthetic 112 MiB collection, proposal processing fell from 2,202 ms to 473 ms, with a 950-byte proposal. Results vary by machine. Short integrity-hashing pauses remain; the JSON database still rewrites the full file, and asynchronous persistence currently covers proposal receipts rather than every save path.

Local server/client tests do not replace a physical two-computer Wi-Fi test.
