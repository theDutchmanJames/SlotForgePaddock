# SlotForge Paddock v1.1.0

Research the full-size car behind your slotcar, compare recorded pace, and find each car's lane records. Dealership reviews now have unmistakable approval and rejection buttons.

## What's new

- **Real Car History:** record livery classification, team, drivers, event, year, race number, qualifying and finishing results, notes, sources and reference photographs.
- **Research tools without built-in AI:** read labelled information from a public webpage, or export an English research template for your own AI and import the completed JSON. Review and select individual suggestions before saving; source links and uncertainty stay with the research.
- **Pace comparison:** compare cars using recorded results, track and conditions, with lane and driver filters. Inspect eligible best laps, typical pace and sustained runs where measured laps are available.
- **Lane records:** see each car's best eligible lap by track and lane, with its driver, date, session and captured configuration. Manual reported records remain distinct from measured Timing results.
- **Manual test conditions:** record track direction and magnet status alongside existing test information.

## Fixes and review

- Replaced the Dealership review dialog's rejection-default dropdown and ambiguous confirmation button with **Approve changes** and **Reject proposal** actions.
- Fixed reference-photo duplication after a failed save and preserved photographs during text-only edits without resending them unnecessarily.
- Strengthened stale-edit protection, research evidence cleanup and incoming-car research previews.
- Added bounded JSON reads, earlier HTML complexity limits and more reliable webpage-request cleanup.
- Reduced unnecessary work in lane-record summaries and excluded non-finite manual lap times.

The generic webpage reader does not use AI, translate pages, run website JavaScript or guarantee a match on every website. Suggestions always require review. Slow laps alone cannot establish a deslot or mechanical problem, and theoretical calculations remain estimates.

## Updating

Close the running app before opening this version. Existing collections and remembered Dealership passwords remain in place. Database schema **11** and Timing integration **v1** are unchanged.

If a previous Dealership change was accidentally rejected through the old dialog, submit it again and choose **Approve changes**. This update does not automatically apply rejected proposals. Use matching Paddock versions when sharing the new research fields.

## Downloads

- **Windows:** `SlotForge.Paddock.1.1.0.exe` — portable app; Node.js is not required.
- **Linux:** x64 and ARM64 AppImage/deb packages.
- **macOS:** universal DMG/ZIP for Intel and Apple Silicon.
- Timing and Telemetry integration handoff ZIPs are also included.

Native Linux and macOS jobs attach their downloads after publication. SHA-256 manifests accompany the downloads. Windows is unsigned; macOS is ad-hoc signed and not Apple-notarised. AppImages need executable permission.

## Validation

**394 automated tests passed**, plus syntax checks, isolated Electron interface checks and Windows packaging. Checks include Dealership approval persistence and local replication, ordinary car edits, research imports, source cleanup, photo retries, manual conditions, comparisons and lane-record edge cases.

Local server/client tests are not a physical two-computer Wi-Fi acceptance test. Webpage extraction tests use fixtures. Native build results are available in GitHub Actions.
