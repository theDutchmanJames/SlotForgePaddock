# SlotForge Paddock v0.19.1

Faster database saves, clearer Connections, and more reliable Dealership sharing.

## Improvements

- **Less waiting:** reduces repeated copying of photographs, duplicate review calculations and redundant database refreshes. In a 27 MiB local test collection, median workshop save time fell from 315 to 169 ms and approval from 1,124 to 487 ms. Actual speed depends on your computer and collection; initial photo transfers and large saves can still take time.
- **Dealership Mode comes first:** its highlighted card now leads the Connections page, with wording suited to home collectors as well as clubs. The shared-change review tab is labelled **Dealership changes**.
- **Reliable review propagation:** approving a repeated car import now sends the review decision to connected copies without duplicating the imported cars.
- **Safer proposal delivery:** failed disk saves preserve queued proposals, and only a valid acknowledgement for the correct proposal clears its retry entry.
- **Better connection recovery:** interrupted first connections, failed disconnect saves, locked copy files and quiet reconnects now leave consistent pairing and status information.
- **Correct background updates:** shared custom fields become available in selectors, refreshes cannot mix collections during switching, and changes arriving during startup are applied. Open editing forms keep their contents.

## Updating and downloads

This is a patch update for v0.19.0. The database remains **schema 11** and the public Timing integration remains **v1**. Keep a complete backup; v0.18.x and older cannot read schema-11 saves.

For Windows, download **SlotForge.Paddock.0.19.1.exe**, close the previous copy and open the new portable app. It is unsigned and does not require Node.js. **SHA256SUMS.txt** covers the Windows app and the included **SlotForge-Paddock-Timing-v1.zip** integration handoff.

Native GitHub jobs attach Linux x64 and ARM64 AppImage/deb downloads, and a universal macOS DMG/ZIP for Intel and Apple Silicon, after publication. Each platform includes a SHA-256 manifest. macOS builds are ad-hoc signed, not Apple-notarised; AppImages require executable permission.

## Validation

**326 automated tests and 187 isolated desktop workflow checks passed**, with no captured renderer errors. Tests used disposable collections, not user data. Network tests use independent instances on one Windows computer; this is not a new physical Wi-Fi or interactive macOS/Linux acceptance test.

See the [full review report](https://github.com/theDutchmanJames/SlotForgePaddock/blob/v0.19.1/docs/reviews/2026-11-01-dealership.md) for fixes, validation boundaries and the separate Timing-client findings, and the [Dealership guide](https://github.com/theDutchmanJames/SlotForgePaddock/blob/v0.19.1/docs/SHARED-CLUB.md) for setup and recovery.
