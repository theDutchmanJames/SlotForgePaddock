# SlotForge Paddock v0.17.0

Build from Scratch gains gearing and motor-performance calculations, and Paddock can now receive reviewed race sessions through its versioned SlotForge Timing host API. This release also includes the fixes from the full review of recent additions.

## Download and upgrade

Download **SlotForge.Paddock.0.17.0.exe** below and open it on Windows. This is a portable application; no installer or Node.js is required. The executable is unsigned, so Windows may show an unknown-publisher warning.

**Create a complete backup in Import & Export before upgrading**, then close the older app. This release uses database schema 9. Existing collections migrate, but older versions, including v0.16.3, cannot open schema-9 saves. Keep the pre-upgrade backup if you need to return to an older version. Collection data remains in your Windows user profile, separate from the executable.

The other downloads are the **Timing integration handoff ZIP** and **SHA256SUMS.txt**, covering both downloadable files. GitHub also provides the tagged source archives.

## Added since v0.16.3

- **Build from Scratch gearing:** calculate the driven-gear/pinion ratio from explicit catalogue specifications or manual tooth counts. Values follow saved drafts, finished cars and optional As built setups.
- **Motor performance estimates:** enter no-load RPM, torque in gf·cm, test voltages and rear tyre diameter to calculate axle RPM, rollout, ideal speed, axle torque and driving force. Compatible brushed DC stall ratings enable estimated peak power and interactive torque/power curves. Save a comparison reference with the draft. These are theoretical estimates, excluding drivetrain losses and tyre slip.
- **Timing integration host:** separate results permission and connection code, stable car identities, signed pre-race configuration captures, structured session results, safe retries, corrections and withdrawals. Imported results appear beside independent manual records. Virtual participants do not add physical-car mileage or records.
- **Integration handoff:** versioned contract, JSON Schema, example sessions and a local demo host for the Timing project's client implementation.
- **Linux/macOS builders:** normal and quick launchers for Linux AppImage/.deb and macOS DMG/ZIP. Build them on the target operating system using the tagged source; this release supplies a Windows binary only.

## Review fixes

- Schema-valid Unicode session names now persist correctly, including after withdrawal.
- Measured laps cannot overlap for one participant across different heats. Earlier affected imports remain readable, show **Needs correction**, and contribute no statistics until corrected or withdrawn.
- The first Timing configuration capture refreshes the desktop's database revision without a false submission notification.
- Extremely small numeric inputs cannot produce infinite force or unusable zero-power curves.
- Quick native builds cannot report untouched installers from a recent previous run as new output.

## Validation and remaining limits

- **253 automated tests**, syntax checks and **154 isolated Electron workflow checks** passed, with no captured renderer errors.
- Packaged source/assets are checked against the reviewed files; release assets include SHA-256 checksums.
- The **Paddock host side** is included. A completed end-to-end Timing product integration still requires Timing's client, cache/outbox and joint acceptance testing. RaceCoordinatorAI integration remains planned.
- Native Linux/macOS execution and physical two-computer Wi-Fi testing remain outstanding. Local automated server/client tests are not physical-network acceptance tests.
- Sudden power loss and large sustained race archives were not tested. The existing whole-document database retains its 200 MiB cap.
