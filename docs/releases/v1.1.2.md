# SlotForge Paddock v1.1.2

Paddock has a new **Collection** icon: a top-down slotcar framed by three display
cards, representing your collection and the cars you build and maintain.

- Updated desktop icons for Windows, macOS and Linux.
- Matching in-app header symbol that follows the selected theme.
- Updated README icon and version information, alongside the SlotForge App
  Collection branding, introductory text and links to the other apps.
- Added editable vector artwork and a repeatable desktop-icon build command.

This is a visual update. Collection storage, Dealership connections, passwords,
Timing and Telemetry APIs are unchanged. Close the previous app before updating.

## Downloads

- **Windows:** `SlotForge.Paddock.1.1.2.exe` — portable app.
- **Linux:** x64 and ARM64 AppImage/deb packages.
- **macOS:** universal DMG/ZIP for Intel and Apple Silicon.
- Timing and Telemetry integration handoff ZIPs and SHA-256 manifests.

GitHub builds and attaches the Linux and macOS downloads after publication.
Windows is unsigned; macOS is ad-hoc signed and not Apple-notarised.

## Validation

**418 automated tests passed**, alongside syntax checks, icon format and size
verification, and an isolated Windows packaged-app startup. The new header was
checked in dark and Ocean light themes with no captured renderer errors. Native
build results are available in GitHub Actions; they do not replace interactive
testing on each operating system.
