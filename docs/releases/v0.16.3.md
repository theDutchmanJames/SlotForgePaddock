# SlotForge Paddock v0.16.3

The first GitHub release of **SlotForge Paddock**: a virtual showroom for your slotcars and a detailed workshop for your builds, parts and setups. The version continues the app's development history; earlier builds used the name SlotForge Database.

## Download and run

Download **SlotForge Paddock 0.16.3.exe** below and open it on Windows. No installer or Node.js is required. The executable is unsigned, so Windows may show an unknown-publisher warning.

A new collection starts empty. Existing collections remain in their original user-data location. Close an older running copy before launching this version, and use **Import & Export → Create backup** before upgrading an existing collection. The portable executable stores collection data in your Windows user profile, not alongside the executable.

`SHA256SUMS.txt` contains the download's SHA-256 checksum. To check a downloaded file in PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\SlotForge Paddock 0.16.3.exe'
```

## Included

- **Virtual showroom:** photographs, spotlight cars, favourites, slideshow and full-screen viewing.
- **Collection management:** searchable gallery and table views, usage labels, ownership details, documents, custom fields and saved views.
- **Detailed setups:** current and factory configurations, gearing ratios, saved setup comparisons and manual performance records.
- **Parts and builds:** grouped inventory, custom icons and colours, assemblies, and an interactive Build from Scratch diagram with saved drafts.
- **Workshop:** editable jobs, maintenance history and reminders, plus a digital toolbox for tools and consumables.
- **Imports and sharing:** reviewed car-file imports, SlotForge Timing JSON imports, manufacturer catalogue templates, complete backups and local-network club submissions.
- **Personalisation:** eight theme presets, custom colours, an editable welcome banner and configurable car overview panels.

See the [README](https://github.com/theDutchmanJames/SlotForgePaddock#readme) for screenshots and the full feature tour.

## Validation and current limits

- All **205 automated tests** passed for this release, along with JavaScript syntax checks.
- Development validation also covered 141 isolated Electron desktop checks; the branding update was checked for collection-path compatibility.
- This release provides the **Windows portable build**. macOS and Linux build targets exist but have not been validated on those platforms.
- Local-network sharing is implemented and tested automatically; physical two-computer Wi-Fi validation remains outstanding.
- Live SlotForge Timing / RaceCoordinatorAI integration and automatic lap-data exchange are planned. Timing JSON car imports are available now.

The project remains under active development. Please report reproducible problems through [GitHub Issues](https://github.com/theDutchmanJames/SlotForgePaddock/issues), including the app version and steps to reproduce them. Avoid attaching private collections unless you intend to share their contents.
