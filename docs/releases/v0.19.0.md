# SlotForge Paddock v0.19.0

One shared club collection across your Paddock computers, with reviewed changes and quieter Timing catalogue refreshes.

## Before updating

**Create a complete database backup in your current version first.** This release migrates collections to **schema 11**. Version 0.18.x and older cannot reopen these saves; retain your pre-update backup if you need to go back. Timing integration remains v1.

## What's new

- **Dealership Mode:** designate one main club computer as the authority for your shared collection. Other trusted Paddock computers keep separate club copies while retaining their personal collections.
- **Review before changes become official:** car and workshop changes enter **REVIEW → Club changes**, including changes proposed on the dealership computer. Compare proposed values, check conflicts and approve or reject them. Stock is checked again before approval.
- **Updates when something changes:** connected club copies receive incremental updates, with small connection heartbeats. Unchanged photos are not repeatedly transferred.
- **Safe reconnection:** outdated club copies show a warning and require a confirmed refresh with a recovery backup. Unsent proposals survive restarts; uncertain deliveries can retry without duplication.
- **Separate access:** trusted-club credentials grant the private club collection. Ordinary browse, submission and Timing credentials retain their existing permissions and cannot access private club replication.
- **Quieter Timing browsing:** status and collection responses now include an optional persistent catalogue revision. Timing can skip catalogue downloads after private edits, pending/rejected proposals or saved race results. Approved public changes trigger a refresh.
- **Updated integration handoff:** contract, response schemas, examples and notes describe the new metadata while preserving the existing pagination and race-results API.

## Downloads

For Windows, download **SlotForge.Paddock.0.19.0.exe**, close the previous copy and open the new portable app. No Node.js or installer is required. The executable is unsigned. **SHA256SUMS.txt** covers the Windows app and **SlotForge-Paddock-Timing-v1.zip** handoff.

Native GitHub build jobs produce these additional downloads after publication:

- Linux x64: AppImage and Debian package.
- Linux ARM64: AppImage and Debian package.
- macOS Intel and Apple Silicon: universal DMG and ZIP.

Each native build includes its own SHA-256 manifest. macOS builds are ad-hoc signed, not Apple-notarised; approval in Privacy & Security may be required. AppImages need executable permission.

## Validation and current limits

314 Paddock automated tests and 68 Timing client tests passed. A direct Timing client/local Paddock host check verified that private edits and result uploads cause status-only checks, while public changes refresh the catalogue. The isolated desktop workflow suite covers 181 checks.

Dealership Mode uses one authoritative computer, with no automatic host failover. It is intended for a trusted local network. Timing browses public cars, captures their configuration for racing and sends reviewed results; it does not manage club replicas. Physical multi-computer Wi-Fi acceptance and interactive macOS/Linux acceptance of this feature remain outstanding.
