# SlotForge Paddock v1.0.0

Your collection, your workshop. SlotForge Paddock reaches its first 1.0 release!

Keep a virtual showroom of your slotcars, or go deeper with parts inventory,
assemblies, scratch builds, setups, workshop jobs and performance history.
Dealership Mode connects your collection across trusted computers, while
SlotForge Timing can select your cars for racing and return finalised results.

## What's improved since v0.20.0

- **Reliable shared updates:** corrected Timing results with reordered JSON fields no longer cause false verification failures or mark connected copies out of date.
- **Safer connection recovery:** failed disk writes cannot leave a new pairing pointing at an unrelated saved copy. Failed reconnect settings saves preserve the existing working connection.
- **Clear hosting retries:** if Dealership setup succeeds but hosting cannot start, the saved password and setup remain available with a Start Dealership retry.
- **Lower save memory use:** JSON output is assembled in batches. A synthetic 50,000-record catalogue used approximately 330 MiB peak process memory instead of 801 MiB in local comparison runs, with identical saved output.
- Removed an obsolete legacy password-dialog entry and strengthened regression coverage for privacy and password revocation.

## Updating

Close the running app before opening the new version. Your existing collection
and remembered Dealership password stay in place. Database **schema 11** and
Timing integration **v1** are unchanged; this version does not require a new
collection or a Timing protocol change.

Dealership Mode uses one remembered password for both Paddock and Timing. If
upgrading an older Dealership installation that has no saved password, use
**Set password…** and then **Start Dealership** in Connections. Use the displayed
address and port; the port may change when hosting restarts. For compatibility
with Timing versions that require eight characters, choose an **8+ character**
password.

## Downloads

- **Windows:** `SlotForge.Paddock.1.0.0.exe` — portable app; Node.js is not required.
- **Linux:** x64 and ARM64 AppImage/deb packages.
- **macOS:** universal DMG/ZIP for Intel and Apple Silicon.
- **Integration:** `SlotForge-Paddock-Timing-v1.zip` — contract, guide and example fixtures.

Native Linux and macOS jobs attach their downloads after publication. SHA-256
manifests accompany the downloads. Windows is unsigned; macOS is ad-hoc signed
and not Apple-notarised. AppImages need executable permission.

## Validation

**342 automated tests and 189 isolated desktop checks passed**, with no captured
renderer errors. An additional 2,000 deterministic JSON/patch/hash round trips
passed. Coverage includes connection recovery, password persistence and
revocation, in-flight Timing uploads, corrected results and exact replication.

Tests use temporary collections and local HTTP connections on Windows. They do
not constitute a new physical multi-computer Wi-Fi test. Memory measurements
are synthetic single-run process peaks; large transfers and durable saves can
still take time.
